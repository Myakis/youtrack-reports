# YouTrack Reports

Расширение браузера для отчётности по задачам YouTrack (`youtrack.office.lan`): выбираете исполнителя —
получаете все его задачи в статусе «Готово» за период и выгружаете их с описанием, тегами, досками и комментариями,
чтобы загрузить в модель для сводки. Работает через вашу сессию YouTrack в браузере.

## Установка

Готовые пакеты — на странице [Releases](https://github.com/Myakis/youtrack-reports/releases/latest).

**Chrome / Edge / Яндекс Браузер:** распакуйте `YouTrackReports-<версия>-chromium.zip` в постоянную папку →
`chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение».
Новая версия — распакуйте поверх той же папки и нажмите ⟳ у YouTrack Reports (без ⟳ Chrome останется на старой версии).

**Обновления.** YouTrack Reports раз в 6 часов проверяет последний релиз на GitHub. Когда выходит новая версия, на значке
появляется «↑», а в шапке — «↑ X.Y.Z». В **Настройках → Версия** есть список изменений, кнопка «Скачать» (пакет
для вашего браузера) и, в Chrome, «Перезапустить расширение»: после распаковки архива поверх папки она перечитывает
файлы и снова открывает YouTrack Reports. Расширение не может само заменить свои файлы, поэтому распаковать архив нужно вручную.

**Firefox (Developer Edition):** один раз `about:config` → `xpinstall.signatures.required` = `false`; затем перетащите
`YouTrackReports-<версия>-firefox.xpi` в окно Firefox. При первом запуске разрешите доступ к `youtrack.office.lan`.

## Как пользоваться

1. Нажмите значок YouTrack Reports — откроется вкладка.
2. **Исполнитель** — начните вводить имя или логин, выберите из списка. ☆ — добавить человека в «Команду»:
   дальше выбирать его можно одним щелчком (и сразу запускается поиск).
   Режим **исполнитель / участник**: «участник» находит и задачи, которые сотрудник делал, а закрыл другой
   (тестировщик) — по истории поля «Исполнитель» у каждой задачи фильтра, как скрипт YoutrackReportByUser.
   Галочка «+ менял / комментировал» — ещё задачи, где он менял поля или комментировал. Колонка «Участие» — как именно.
3. **Статус** — по умолчанию «Готово»; можно несколько через запятую («Ревью, Готово» — любой из них).
   **Проект**, **Тип** («Frontend, Mobile»), **Тег** («CashDash») — необязательно.
   **Доска** — только задачи этой доски (у доски со спринтами можно выбрать один спринт). С доской сотрудник
   необязателен: без него покажутся все задачи доски, подходящие под статус, тип, тег и период.
4. **Период** — этот / прошлый месяц, квартал, год, свой; «по дате» — решения, обновления или создания задачи.
5. «Найти» (Enter). Галочка **Доски** — определить доски и спринты задач (дольше на больших досках).
6. Щелчок по задаче — справа поля, описание и комментарии; двойной щелчок — открыть в YouTrack.
   Фильтр над таблицей сужает найденное; снимите галочку у задачи, чтобы не выгружать её.
7. **Выгрузить…** (Ctrl+S) — Markdown (лучше всего для модели), JSON, CSV для Excel или TXT как в скрипте; можно отключить описание,
   комментарии, поля и добавить инструкцию для модели. **✦ Для ИИ** — открыть чат с моделью chat.office.lan
   (вкладка «✦ ИИ» справа): отмеченные задачи и инструкция для отчёта уже подставлены — поправьте и «Отправить».
   Нужен вход в chat.office.lan, как для ИИ в LogDesk.
8. «Запрос YouTrack» — итоговый запрос на языке поиска YouTrack; его можно поправить вручную (`↺ Из полей` — вернуть).

## Вход

YouTrack Reports сначала использует сессию браузера. Если YouTrack не пускает (бывает, когда API требует токен):
YouTrack → профиль → «Безопасность аккаунта» → «Новый токен» (область YouTrack) → вставьте в «Настройки».
Токен хранится только в хранилище расширения в этом браузере.

## Как это устроено

Код расширения — в папке `app/`; в корне — README, CHANGELOG и `.github` (CI и релиз).

- `app/src/core/youtrack.ts` — REST API YouTrack: `/api/issues` страницами по 100, пользователи, проекты.
  Запрос: `assignee: {логин} state: {Ревью}, {Готово} type: {…} tag: {…} resolved date: …`.
- Доски: в REST у задачи нет поля «доска», поэтому берутся доски (`/api/agiles`) проектов найденных задач
  и состав их спринтов. Доска без спринтов подписывается просто названием, со спринтами — «Доска / Спринт».
- `app/src/core/participation.ts` — поиск по участию: история поля «Исполнитель» по всему фильтру одним потоком
  (`/api/activities?issueQuery=…`, до 50 000 задач). Если YouTrack так не умеет — у каждой задачи отдельно
  (`/api/issues/{id}/activities`), как в скрипте, до 3 000 задач.
- `app/src/core/export.ts` — Markdown / JSON / CSV / TXT; `app/src/core/prompts.ts` — запросы к модели.
- Интерфейс — React + [shadcn/ui](https://ui.shadcn.com) (Radix, Tailwind v4): `app/src/app/App.tsx` — страница и поиск,
  `app/src/app/components/` — фильтры, таблица, детали, ИИ-чат (`AiPanel.tsx`), окна; `app/src/components/ui/` — компоненты shadcn.
  Логика YouTrack, выгрузки и обновлений — в `app/src/core/` и от React не зависит.

## Для разработки

Нужен Node.js 22 или новее.

```
cd app
npm ci
npm run typecheck
npm test
npm run dev          # страница на тестовых данных: http://localhost:8778/app.html, пересборка при изменениях
npm run build        # app/dist/firefox, app/dist/chromium и пакеты в app/release/
npm run icons        # пересоздать иконки
```

Для разработки в Chrome удобно загрузить распакованное расширение прямо из `app/dist/chromium`: после `npm run build`
достаточно нажать ⟳ у YouTrack Reports на `chrome://extensions`.

Новый компонент shadcn: `npx shadcn@latest add <имя>` — (из папки `app`) — файл появится в `app/src/components/ui/`. CLI иногда пишет
`import { cn } from "cn"` и ставит пакет `cn` — замените импорт на `@/lib/utils` и удалите пакет (`npm uninstall cn`).
Цвета — в `app/src/app/globals.css` (переменные shadcn, акцент — фиолетовый).

Страница без расширения, на тестовых данных: `npm run dev` (или `bun run dev`) → `http://localhost:8778/app.html`.
Код и стили пересобираются при сохранении — обновите страницу. Порт можно сменить: `PORT=9000 npm run dev`.

## Релиз

Пайплайны GitHub Actions (`.github/workflows/`):

- **CI** — на каждый пуш в `main` и пул-реквест: типы, тесты, сборка; пакеты лежат в артефактах запуска 14 дней.
- **Release** — проверка, сборка и [GitHub Release](https://github.com/Myakis/youtrack-reports/releases) с пакетами
  для Chrome и Firefox. Описание релиза — раздел этой версии из `CHANGELOG.md`.

Как выпустить версию:

1. Опишите изменения в `CHANGELOG.md` — раздел `## X.Y.Z — ДД.ММ.ГГГГ` сверху (по ходу работы можно копить их
   в разделе «## Не выпущено» и перед релизом переименовать его).
2. Поднимите `version` в `app/package.json` до той же X.Y.Z.
3. Закоммитьте и отправьте в `main` — всё. Релиза этой версии ещё нет, поэтому он соберётся сам: тег `vX.Y.Z`,
   пакеты и описание — раздел версии из `CHANGELOG.md`. Его же расширение покажет в «Настройки → Обновления → Что нового».

Пуш без новой версии релиз не выпускает. Запустить вручную тоже можно: тегом `git tag vX.Y.Z && git push origin vX.Y.Z`
или кнопкой GitHub → Actions → Release → Run workflow. Релиз не соберётся, если в `CHANGELOG.md` нет раздела версии
(или тег не совпадает с версией в `app/package.json`).
