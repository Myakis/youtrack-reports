# История изменений TrackDesk

## 0.7.0 — 05.11.2026
- Обновления из GitHub: в **Настройках → Версия** — текущая версия, проверка, список изменений и кнопка «Скачать»
  (пакет для вашего браузера). В Chrome после распаковки архива поверх папки — «Перезапустить расширение».
- Раз в 6 часов TrackDesk сам проверяет новый релиз: на значке появляется «↑», в шапке — «↑ X.Y.Z».

## 0.6.5 — 29.10.2026
- «Обоснование повышения» — краткий текст для колонки «Письменное обоснование пересмотра» в Google-таблице:
  4–7 предложений обычным текстом, без списка задач и оформления — общее количество задач, польза для команды
  и продукта, что сотрудник умеет, почему его стоит повысить.

## 0.6.4 — 29.10.2026
- В таблице — колонка «Статус» (сортируется щелчком по заголовку).

## 0.6.3 — 29.10.2026
- «Участник» — снова как в 0.5.0: история каждой задачи фильтра, у первых 3 000 задач (общая лента изменений
  и замер скорости убраны — на рабочем YouTrack это оказалось медленно). «Показать найденное» осталась.

## 0.6.2 — 29.10.2026
- «Участник» быстрее на больших фильтрах: сначала замер — история первых 32 задач по одной; общая лента изменений
  показывает процент и оставшееся время, и если она заметно медленнее проверки по задачам — TrackDesk переключается
  сам («Лента изменений медленная — проверяю по задачам»). Страница ленты — 1000 записей, по задачам — 8 запросов сразу.

## 0.6.1 — 29.10.2026
- Понятнее ход поиска по участию: «Задач в фильтре: N · читаю историю изменений: M записей, затронуто задач K».

## 0.6.0 — 29.10.2026
- «Участник» без лимита: проверяются все задачи фильтра, сколько бы их ни было. Если общая лента изменений
  недоступна — очередью пакетами по 3 000 задач, с ходом и оценкой оставшегося времени.
- «Показать найденное» — остановить проверку и показать задачи из уже проверенной части.

## 0.5.1 — 29.10.2026
- «Участник» на больших фильтрах: история читается общей лентой изменений YouTrack (500 изменений за запрос) —
  до 20 000 задач фильтра вместо 3 000. Если лента недоступна или не отфильтрована по задачам — как раньше,
  история каждой задачи (как в скрипте YoutrackReportByUser).

## 0.5.0 — 29.10.2026
- Вкладка «✦ ИИ» — цель разговора: «Отчёт» или «Обоснование повышения». Для повышения — поля «Текущий грейд»,
  «Целевой грейд» и «Описание сотрудника» (заполняет руководитель, запоминаются для каждого сотрудника); из них
  и найденных задач собирается запрос на документ для комиссии: резюме, ключевые достижения с ключами задач,
  масштаб и сложность, качества, соответствие грейду, зоны роста. Текст можно поправить перед отправкой.

## 0.4.1 — 29.10.2026
- Доступ к chat.office.lan и youtrack.office.lan: если запрос браузера не появился — подсказка, где включить доступ
  (Chrome: «Доступ к сайтам» в chrome://extensions, Firefox: about:addons); выданное там подхватывается сразу.

## 0.4.0 — 29.10.2026
- «✦ Для ИИ» открывает чат с моделью chat.office.lan прямо в TrackDesk (вкладка «✦ ИИ» справа): в нём уже есть
  отмеченные задачи — как в таблице: доски, теги, участие, поля, описания и комментарии — и инструкция для отчёта.
  Инструкцию можно поправить; дальше — уточняющие вопросы, выбор модели, «Стоп», копирование ответа.
- Объём данных в токенах виден заранее; описания и комментарии можно не отправлять, если не влезают.
- Вкладки справа: «☰ Детали» и «✦ ИИ».

## 0.3.1 — 29.10.2026
- «Статус» — выпадающий список с галочками: статусы берутся из задач YouTrack (выбранного проекта), можно отметить
  несколько, добавить свой («Другой статус…») или выбрать «Любой статус».

## 0.3.0 — 29.10.2026
Сверено со скриптом YoutrackReportByUser:
- Статус — «state: {Ревью}, {Готово}» (поле статуса; запятая — «или»), как в скрипте. Было «#{…}» — значение любого поля.
- Поля «Тип» и «Тег»: «type: {Frontend}, {Mobile}», «tag: {CashDash}».
- «Участник» — как в скрипте: история каждой задачи фильтра, поле «Исполнитель» (ставили или снимали сотрудника).
  «Менял задачу» и «комментировал» — отдельной галочкой «+ менял / комментировал», по умолчанию выключена.
- Задачи, пользователи и история листаются до пустой страницы: сервер может отдавать меньше, чем просили (~42 записи).
- Выгрузка в TXT как в скрипте: «- KEY: название (Описание: …)».

## 0.2.0 — 29.10.2026
- Режим «участник»: задачи, где сотрудник исполнитель сейчас, был исполнителем раньше (по истории задачи),
  менял задачу (например, перевёл в тестирование) или комментировал — даже если закрыл задачу другой человек.
  В таблице, деталях и выгрузке — колонка «Участие». Нужен период или проект: история смотрится по задачам фильтра.

## 0.1.4 — 29.10.2026
- Исполнитель ищется через «assignee: {логин}» — так же, как в самом YouTrack (раньше «for:»).
- Статус по умолчанию — «Готово» (как в YouTrack), было «Готова».

## 0.1.3 — 29.10.2026
- Ничего не найдено — TrackDesk убирает условия запроса по очереди и показывает, какое отсекает задачи.
- Если «for:» не находит задачи исполнителя, подбирается «Исполнитель: {логин}» или «Assignee: {логин}» —
  кнопкой в плашке; выбор запоминается и меняется в «Настройках».
- Кнопка «Открыть запрос в YouTrack» — проверить тот же запрос в самом YouTrack.

## 0.1.2 — 29.10.2026
- Пусто при поиске «по дате решения» — TrackDesk проверяет, есть ли задачи без периода. Если у задач в этом статусе
  нет даты решения (статус в YouTrack не «решённый»), объясняет это и предлагает «Искать по дате обновления» или «Всё время».

## 0.1.1 — 29.10.2026
- Сортировки больше нет в запросе YouTrack (таблица сортирует сама) — из-за неё YouTrack мог не понять запрос.
- Если YouTrack не понял запрос, TrackDesk проверяет каждую часть отдельно и показывает, какая неверна;
  для статуса — подсказывает, какие статусы реально есть у задач проекта. Поле «Статус» — со списком статусов.

## 0.1.0 — 29.10.2026
- Первая версия: поиск задач по исполнителю и статусу («Готова») за период, команда (☆), проект, свой запрос YouTrack.
- Доски и спринты задач, теги, все поля, связи, описание и комментарии.
- Выгрузка в Markdown / JSON / CSV, «✦ Для ИИ» — Markdown с инструкцией для модели в буфер обмена.
- Вход через сессию браузера или постоянный токен YouTrack.
